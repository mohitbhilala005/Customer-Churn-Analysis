# 📊 Customer Churn Analysis

## 📌 Project Overview

Customer churn is a major business challenge because acquiring a new customer can be more costly than retaining an existing one.

This project analyzes customer churn data to identify the key patterns and customer segments associated with churn. The analysis uses **MySQL** for data exploration and business analysis, with **Power BI** used to develop an interactive dashboard.

The objective is to transform customer-level data into actionable insights that can support customer retention and business decision-making.

---

## 🎯 Business Objectives

The project aims to:

- Measure the overall customer churn rate
- Identify customer segments with high churn
- Analyze churn across contract types
- Evaluate the relationship between customer tenure and churn
- Analyze churn by payment method and internet service
- Examine the relationship between monthly charges and churn
- Analyze the impact of support and protection services
- Identify high-risk customer segments
- Develop data-driven recommendations for improving customer retention

---

## 🛠️ Tools & Technologies

- **MySQL** – SQL-based data analysis
- **Power BI** – Interactive dashboard and visualization
- **CSV / Excel** – Data source and preprocessing
